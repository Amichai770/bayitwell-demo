# Kehuna Academy → Mishmeret

Working files for the rebrand of Kehuna Academy (kehunacademy.com) into Mishmeret, a daily companion for Kohanim.

- `REBRAND-AND-APP-PLAN.md`: what exists today on Kajabi, the name and positioning, the five-part app, content debt, and sequencing.
- `prototype/mishmeret.html`: a self-contained mobile-first prototype of the app. Five screens: Tamid, Duchan, Mishmar, Beit Midrash, Ask. Published as a claude.ai artifact; it also opens directly in a browser.

This folder sits in the Bayitwell demo repository only because this session was bound here. When the app is built for real it should move to its own repository.
